# 🚖 Mega City Cab – Java EE Web-Based Cab Booking System

## 📌 Project Overview
Mega City Cab is a **web-based cab booking system** developed as part of my **Campus Assignment**.  
The system helps streamline cab management operations, allowing an **admin** to handle customer bookings, assign drivers,  
manage cars, and generate invoices efficiently through a **web interface** using JSP and Servlets.

## 🛠️ Tech Stack
- **Java EE (Servlets & JSP)** – Core development
- **JDBC** – Database connectivity (if applicable)
- **HTML, CSS, JavaScript** – Frontend for a user-friendly interface
- **Git & GitHub** – Version control and project management

## 🎯 Features
✅ **Admin Authentication** – Secure login/logout system  
✅ **Customer Management** – Register, update, and delete customer records  
✅ **Booking System** – Create, modify, and cancel bookings  
✅ **Driver & Car Assignment** – Manage driver and car details  
✅ **Billing & Invoices** – Calculate fares, apply taxes, and generate invoices  
✅ **Reports** – View system logs and booking summaries  
✅ **User-Friendly Interface** – Web-based UI using JSP and HTML
